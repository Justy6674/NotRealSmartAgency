# /gstack-qa-only

Report-only QA testing.

## What to do

Invoke the **`qa-only`** skill with the Skill tool, passing anything the
user typed after the command as its arguments. Follow that skill's instructions
from its first step; do not summarise, shortcut, or re-implement them here.

## When this applies

Systematically tests a web application and produces a structured report with health score, screenshots, and repro steps — but never fixes anything. Use when asked to "just report bugs", "qa report only", or "test but don't fix". For the full test-fix-verify loop, use /qa instead. Proactively suggest when the user wants a bug report without any code changes. Voice triggers (speech-to-text aliases): "bug report", "just check for bugs".
